# Cheatz Elite

## Installation

Copy and run the following commands:

```bash
git clone https://github.com/ogotto/Cheatz-Elite.git
cd Cheatz-Elite
npm install
pm2 start index.js --name "Cheatz Elite"
pm2 save
```
## DELETE THE EXTRA V in .envV and add TOKEN!

## Updating download

```bash
cd Cheatz-Elite
git pull
npm install
pm2 restart "Cheatz Elite"
pm2 save
```
## Updating upload

```bash
git add .
git commit -m "Update bot"
git push
```
